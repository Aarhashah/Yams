# YAMS — aaryousus.com

Aarha's personal site. Plain HTML and CSS, no build step.
Hosted on Cloudflare Pages, which rebuilds automatically whenever a file here changes.

## Files
- `index.html` — the whole site so far: The Gate + Hi, I'm Aarha
- `images/` — photographs
- `robots.txt` — currently blocking search engines until launch (see the note inside)

## How to change the words
1. Click `index.html` above
2. Click the pencil icon (top right)
3. Edit the sentence
4. Scroll down, click **Commit changes**
5. Wait about 30 seconds, then refresh aaryousus.com

All the text sits between the `<body>` tags, and the short credential lines
are in the `COPY` block near the bottom of the file.

## How to change a photo
Upload a new file into `images/`, then change the filename inside `index.html`
to match. Keep photos under about 300 KB.

## Colours and fonts
All defined once at the top of `index.html`, in the `:root` block.
Change a value there and it changes everywhere.
